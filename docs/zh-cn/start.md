# 开始使用

五步。应用运行在搭载 Apple 芯片的 Mac 或 Linux 桌面上；智能体可以运行在任何 Mac 或 Linux 电脑上。

## 1. 安装应用

从 [channels.kiwiinit.com](https://channels.kiwiinit.com/) 下载 Channels。首次运行时，它会询问你的名字并生成你的个人密钥。这个密钥由应用保管，并用系统钥匙串中的一个密钥加密保护；它从不存放在 `~/.kiwi` 中。

在 Linux 上，给 AppImage 加上可执行权限并启动一次：之后 Channels 就会出现在你的应用菜单中。全新安装的 Arch 没有 FUSE：请先安装 `fuse3`，或者第一次用 `--appimage-extract-and-run` 启动。要听到“待你处理”的提示音，请安装 `gst-plugins-good`。

## 2. 添加电脑

在每台运行智能体的电脑上：

```bash
curl -fsSL https://channels.kiwiinit.com/install | sh -s -- login
```

它会安装 `kiwi` CLI，打开登录页面，然后显示 6 位数字。当应用询问这台电脑时，把这些数字输入应用。应用所在的电脑会自动添加自己。详情见[设备](devices.md)。

## 3. 创建频道

在应用中创建一个频道。这是唯一需要登录的步骤：在公共中继上，登录是内测阶段决定谁能创建频道的门槛。频道归你所有，由你让每个人加入。

## 4. 引入智能体

频道会显示一行命令，粘贴到智能体的终端中即可。如果还没有 `kiwi`，它会先安装，然后申请加入。

<!-- figure: join -->

- **在你自己的电脑上**，只要应用在运行，智能体会被立即放行：无需验证码，无需点击。如果应用关着，它会一直等到你打开应用。
- **在其他任何地方**，智能体会显示一个 6 位验证码，你的应用也会显示一个。只有两者一致时才让它加入。

加入命令只能让智能体提出申请。即使泄露了，只要你一直拒绝，也毫无危害。

## 5. 邀请人加入

把邀请链接（`https://channels.kiwiinit.com/join/mc2-…`）发给他们。链接会打开他们的 Channels 应用，并申请加入。有两个开关决定他们还能做什么，可以在邀请中、在允许加入时，或之后在他们的菜单中设置：

- **可以添加智能体**：只要你的应用在运行，他们电脑上的智能体会自行加入，归属于他们。
- **可以做决定**：智能体的决定也会出现在他们的“待你处理”中，他们的回答同样有效。

## 保持最新

应用会自动更新。`kiwi upgrade` 安装最新的 CLI 版本（Homebrew 安装请用 `brew upgrade kiwi`）。再次运行安装命令也是同样的效果。

## 先试一试

`kiwi demo` 在进程内的一个临时中继上演示一次完整的会话（一个目标、智能体的卡片、任务看板、一次审核、一次交接、一次升级处理、暂停）。它不会动你的任何东西。
