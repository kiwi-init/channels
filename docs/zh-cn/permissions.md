# 权限提示

当 Claude Code 要询问能否运行某个操作时，同样的问题会出现在应用的**待你处理**中：智能体、文件夹、它想运行什么以及它自己给出的理由，并附有**允许一次**和**拒绝**。终端提示会一直保留。先回答的一方生效。

<!-- figure: permission -->

它默认开启，适用于 Claude Code。它不改变任何模式或规则：只在 Claude Code 本来就要询问时才会运行。

## 谁可以回答

- **允许一次**只能由智能体所属的人发出。
- **拒绝**可以由那个人或频道所有者发出。
- 其他人能看到卡片，但无法回答。智能体永远不会回答自己的请求。

应用中没有“始终允许”：规则保留在 Claude Code 的设置中，那里的拒绝规则仍然优先。被拒绝的调用会告诉 Claude “Denied from the Kiwi app by NAME”。

## 等待

最长 30 分钟。之后卡片会显示：由 NAME 允许、由 NAME 拒绝、已在终端中回答、应用中无人回答，或会话已结束。终端提示在被回答之前会一直保留。

## 显示的内容

| 工具 | 卡片显示的内容 | 限制 |
| --- | --- | --- |
| Bash | 命令及其描述；关闭沙箱或在后台运行的命令会被标出 | 2,000 个字符。关闭沙箱时只能拒绝 |
| Edit、Write、MultiEdit、NotebookEdit | 路径、新内容以及被替换的文本 | 每项 4,000 个字符。只有全部显示时才能允许 |
| WebFetch | URL | |
| MCP 工具 | 服务器、工具及其参数 | 2,000 个字符。超出时只能拒绝 |

除此之外不会发送任何内容：没有其他文件、输出、环境变量或对话记录。

## 留在终端中的内容

- 其他任何工具。
- 任何看起来像机密的内容：令牌或密钥、`Authorization` 或 cookie 请求头、密码参数、URL 中的凭据、webhook URL、JWT、看起来随机的长字符串、从 `$TOKEN` 或 `$(…)` 读取的值。
- 对 `.env` 文件的编辑。
- 包含不可见字符或改变文字方向字符的命令、路径或文件夹。
- 已有一个提示在等待时出现的第二个提示。
- 在频道中没有所属人的智能体、处于暂停中的频道，或 Kiwi 没有为其分配席位的会话。

## 工作原理

加入时会运行 `kiwi hooks install`，它为 Claude Code 添加一个 `PermissionRequest` 钩子：`kiwi hook permission`，超时时间 30 分钟。在 `auto` 模式下，分类器会自行批准大多数调用，所以只有它不批准的调用才会进入“待你处理”。

钩子以智能体的席位发出请求，并等待一个已签名的回答。当调用在终端中得到处理时，它会从会话的对话记录中发现这一点，清除卡片，并且不做任何决定。它在回答前还会再检查一次，所以终端中的回答永远不会被覆盖。
