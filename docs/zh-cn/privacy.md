# 隐私

Channels 的设计让运营它的人读不到你写的内容。本页涵盖各个应用（Mac、Linux、iPhone、Android）、CLI 以及位于 `channels.kiwiinit.com` 的公共中继。

## 我们看不到什么

- **你的消息、文件、名字、角色和频道名称**。它们在离开你的设备之前就已在设备上加密，只有频道成员能打开。
- **你的密钥**。你的个人密钥在你的设备上生成，并始终留在那里。

## 中继能看到什么

为了传递加密消息，中继能看到它们的形态，而不是内容：

- 消息何时发送、大小以及数量；
- 房间 ID 和成员的公钥；
- 连接的 IP 地址，以及每个密钥何时连接；
- 每个成员读到了哪里：一个数字和一个时间，绝不是读了什么；
- 你登录时的 GitHub 用户 ID。不含名字或邮箱。

频道关闭时，中继会删除它，房间 ID 和加入码也随之删除。

## 还有谁会接触你的数据

- **GitHub**，在你登录或连接仓库时。我们会得到你的 GitHub 用户 ID，以及你所连接仓库的事件。
- **Apple 和 Google**，用于手机通知。推送只带有一个随机标签和一个数字，绝不包含房间、名字或任何文字。
- **Stripe**，如果你为方案付费。Stripe 处理你的支付信息；我们只知道你的 GitHub ID 在付费方案中。
- **Cloudflare**，托管公共中继。

## 我们不做什么

- 应用中没有广告、没有追踪，也没有分析统计。
- 我们不出售也不分享你的数据。

## 你的选择

- **离开频道**，你的密钥会被立即吊销。
- **关闭频道**（所有者），中继会直接删除它。成员的设备会清除各自的副本。
- **运行你自己的中继**，就不会经过我们的中继。参见[自托管](self-hosting.md)。

## 联系方式

关于隐私的问题：请在 [github.com/kiwi-init/channels](https://github.com/kiwi-init/channels/issues) 提交 issue。完整的信任模型见[安全](security.md)。
