# プライバシー

Channels は、運営する側があなたの書いたものを読めないように作られています。このページは、アプリ（Mac、Linux、iPhone、Android）、CLI、`channels.kiwiinit.com` の公開リレーを対象とします。

## 私たちに見えないもの

- **あなたのメッセージ、ファイル、名前、ロール、チャンネル名。** デバイスを離れる前にあなたのデバイスで暗号化され、チャンネルのメンバーだけが開けます。
- **あなたの鍵。** あなたの個人の鍵はあなたのデバイスで作られ、そこから出ません。

## リレーに見えるもの

暗号化されたメッセージを運ぶために、リレーにはその内容ではなく形が見えます。

- メッセージがいつ送られたか、そのサイズと件数
- ルーム ID とメンバーの公開鍵
- 接続元の IP アドレスと、各鍵がいつ接続したか
- 各メンバーがどこまで読んだか: 数値と時刻だけで、何を読んだかは見えません
- サインインしたときの GitHub のユーザー ID。名前やメールアドレスは見えません

チャンネルが閉じると、リレーはそのチャンネルを削除し、ルーム ID と参加コードも一緒に削除します。

## あなたのデータに触れるほかの事業者

- **GitHub**: サインインやリポジトリの接続のとき。私たちが受け取るのは、あなたの GitHub のユーザー ID と、接続したリポジトリのイベントです。
- **Apple と Google**: スマートフォンの通知のため。プッシュにはランダムなタグと数値だけが含まれ、ルーム、名前、テキストは含まれません。
- **Stripe**: プランの料金を支払う場合。支払い情報は Stripe が扱います。私たちが知るのは、あなたの GitHub ID が有料プランであることだけです。
- **Cloudflare**: 公開リレーをホストしています。

## 私たちがしないこと

- アプリに広告、トラッキング、アナリティクスはありません。
- あなたのデータを販売したり共有したりしません。

## あなたが選べること

- **チャンネルから退出**すると、あなたの鍵はすぐに無効になります。
- **チャンネルを閉じる**（オーナー）と、リレーはそれを完全に削除します。メンバーのデバイスもコピーを消去します。
- **自分のリレーを動かせば**、私たちのリレーを何も通りません。[セルフホスティング](self-hosting.md)を参照してください。
