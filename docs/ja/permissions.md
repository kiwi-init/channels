# 権限の確認

Claude Code が何かを実行してよいか尋ねようとすると、同じ質問がアプリの**あなたの対応待ち**にも表示されます。エージェント、フォルダー、実行しようとしているもの、その理由が示され、**許可**（1 回のみ）と**拒否**のボタンがあります。ターミナルの確認もその間ずっと表示されたままです。先に答えた方が有効になります。

<!-- figure: permission -->

Claude Code では既定でオンです。モードもルールも変えません。Claude Code がもともと尋ねる場合にだけ動きます。

## 誰が答えられるか

- **許可**（1 回のみ）できるのは、エージェント自身の人間だけです。
- **拒否**できるのは、その人間かチャンネルのオーナーです。
- それ以外の人にもカードは見えますが、答えられません。エージェントが自分の確認に答えることはありません。

アプリから「常に許可」はできません。ルールは Claude Code の設定に残り、そこにある拒否ルールが常に優先されます。拒否された呼び出しは、Claude に「Denied from the Kiwi app by NAME」と伝えます。

## 待ち時間

最大 30 分です。その後、カードには「NAME が許可」「NAME が拒否」「ターミナルで回答済み」「アプリから回答なし」「セッション終了」のいずれかが表示されます。ターミナルの確認は、答えるまで表示されたままです。

## 表示される内容

| ツール | カードに表示されるもの | 上限 |
| --- | --- | --- |
| Bash | コマンドとその説明。サンドボックスがオフのコマンドやバックグラウンドのコマンドには印が付きます | 2,000 文字。サンドボックスがオフなら拒否のみ |
| Edit, Write, MultiEdit, NotebookEdit | パス、新しい内容、置き換えられるテキスト | それぞれ 4,000 文字。すべて表示されたときだけ許可できます |
| WebFetch | URL | |
| MCP ツール | サーバー、ツール、その引数 | 2,000 文字。それを超えると拒否のみ |

ほかには何も送りません。ほかのファイル、出力、環境、トランスクリプトは送られません。

## ターミナルに残るもの

- ほかのツール。
- 秘密情報に見えるもの: トークンや鍵、`Authorization` ヘッダーや Cookie ヘッダー、パスワードのフラグ、URL 内の認証情報、Webhook の URL、JWT、ランダムに見える長い文字列、`$TOKEN` や `$(…)` から読み取った値。
- `.env` ファイルの編集。
- 不可視文字や文字の向きを変える文字を含むコマンド、パス、フォルダー。
- 1 つの確認を待っている間の 2 つ目の確認。
- チャンネルに人間がいないエージェント、一時停止中のチャンネル、Kiwi が席を持たないセッション。

## 仕組み

参加時に `kiwi hooks install` が実行され、Claude Code に `PermissionRequest` フックとして `kiwi hook permission` を 30 分のタイムアウトで追加します。`auto` モードでは分類器がほとんどの呼び出しを自分で承認するので、あなたの対応待ちに届くのは分類器が承認しないものだけです。

フックはエージェントの席からリクエストを投稿し、署名付きの回答を待ちます。ターミナルで決着がつくと、フックはそれをセッションのトランスクリプトで確認し、カードを消して何も決めません。答える直前にもう一度確認するので、ターミナルでの回答が上書きされることはありません。
