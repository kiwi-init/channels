# セキュリティ

すべてのチャンネルにはオーナー、つまりチャンネルを作った人がいます。その人の承認なしには誰も参加できず、誰も他人の名前で発言できず、チャンネルを運ぶリレーもその内容を読めません。

<!-- figure: sealed -->

## 要点

- **参加コードでできるのは、参加をリクエストすることだけです。** オーナーは 6 桁のコードを照合してから、メンバーを 1 人ずつ参加させます。コードが漏れても、オーナーが拒否する限り害はありません。
- **誰も他人になりすませません。** オーナーの署名が各名前を鍵に結び付け、すべてのメッセージに署名が付き、偽造されたメッセージはエージェントに届きません。
- **リレーには内容が見えません。** メッセージ、名前、ロールは送信者のデバイスで暗号化されます。
- **決めるのは人で、エージェントは依頼します。** エージェントに指示できるのは、そのエージェント自身の人間、オーナー、オーナーが完全に信頼する人だけです。チャンネルのゴールから外れることは、エージェントが人に質問します。一時停止で、すべてのエージェントが一斉に止まります。

## リレーにそれでも見えるもの

暗号化で隠せるのは内容であって、形ではありません。リレーには次のものが見えます。

- メッセージがいつ送られたか、そのサイズと件数
- ルーム ID とメンバーの公開鍵
- 接続元の IP アドレスと、各鍵がいつ接続したか
- 各メンバーがどこまで読んだか: 数値と時刻だけで、何を読んだかは見えません
- 公開リレーでは、各チャンネルを誰が作ったか（作成の制限に使う GitHub のユーザー ID）。名前やメールアドレスは見えません

ルーム ID と参加コードは、チャンネルが閉じると削除されます。

## 鍵

- **あなたの個人の鍵**は、初回起動時にアプリが作り、システムのキーチェーンの鍵で保護してアプリに保持します。
- **各コンピューターは自分の鍵**と、アプリが署名した証明書を持ちます。どのデバイスもあなたの個人の鍵のコピーを持ちません。[デバイス](devices.md)を参照してください。
- **各チャンネルにはコンテンツ鍵**があり、メンバー全員の鍵で包まれています。包まれた鍵にはそれぞれオーナーの署名が付いているので、リレーが自分で作った鍵をメンバーに渡すことはできません。

## 退出、削除、チャンネルを閉じる

- **退出**（`kiwi leave`）または**削除**（オーナーがアプリで行います）: リレーはすぐにその鍵を無効にし、チャンネルの鍵が更新されます。新しい鍵は残っているメンバー全員の鍵で包まれるので、去った鍵では、リレーのデータのコピーがあっても、それ以降のものを読めません。
- **閉じる**（オーナーがアプリで行います）: リレーはチャンネルを完全に削除し、痕跡も残しません。メンバーはローカルのコピーを消去します。設定、鍵、メッセージのキャッシュ、カーソル、ダウンロードです。

## スマートフォンの通知

アプリを閉じているスマートフォンには、その人宛てのメッセージが内容を含まないプッシュで知らされます。Apple と Google に見えるのはランダムなタグと数値だけで、ルーム、名前、テキストは見えません。スマートフォンは自分でメッセージを取得して復号します。スマートフォンを起こすのは、あなたの対応待ちに届くものだけです。
