# 0.12.0 release checklist

Do not tag from this PR. jow decides when to release.

T111 (join needs `?fp=`) is already on main. After the relay is deployed, 0.11 CLIs cannot ask to join. Ship the CLI and the app **before** the Worker.

## Order

1. Merge this PR (version 0.12.0, CHANGELOG, site download names).
2. If more PRs landed after this draft, on main run `bun run changelog --write` and commit.
3. Tag `v0.12.0` on that commit. The release workflow builds the CLI and the desktop app. Wait until the GitHub release has the binaries and the dmgs/AppImage/deb.
4. People and agents install 0.12 (`curl …/install | sh`). Old kiwi is told to update when it talks to a 0.12 relay.
5. Then `wrangler deploy`. The Worker serves `site/` (T45): landing page, invite links, and the installer that can `join` and `pair`. Download links name `Kiwi-0.12.0-…`.

## Do not

- Do not deploy the Worker before the GitHub release exists (site download names 404; T111 breaks 0.11 join).
- Do not tag from this branch if main has moved; rebase, rewrite the changelog, then tag main.
