# 0.20.0: what "stable" means

jow asked for "the smallest, fastest and most stable" app, and called 0.20.0 the
first stable version. This page turns that into numbers and a list. 0.20.0 ships
when every budget below holds in CI and every must-fix task is merged. Nothing is
waived without jow saying so.

The four audits that measured today's baseline are T669 (app speed and size),
T670 (agent side), T671 (relay, protocol and CI) and T672 (app stability).

## Size budgets

| What | Today (0.19.2) | 0.20.0 budget | Held by |
|---|---|---|---|
| Dashboard first-load JS | 736 KB | ≤ 700 KB | `scripts/web-bundle.ts` (lowered from 745 000) |
| Mac dmg / zip | 163–174 MB | ≤ 150 MB | a new size check in `desktop / package` |
| Installed app on disk | 404 MB | ≤ 320 MB | the same check |
| `kiwi` CLI download | 64–89 MB | ≤ 30 MB, served compressed | the release job |

## Speed budgets

Measured by `scripts/perf-scale.ts`: a local relay and headless Chromium with 10
agents, 100 tasks and 2000 messages, at 4x CPU. The medians of five runs must hold.

| What | Today | 0.20.0 budget |
|---|---|---|
| Desktop cold start, launch to first paint (real machine) | 2.2–2.9 s | ≤ 1.2 s |
| Reload to first screen | 944 ms | ≤ 400 ms |
| Revisiting a channel | 36 ms | ≤ 50 ms |
| Tasks / Agents / Conversation tab | 240 / 281 / 351 ms | ≤ 100 ms each |
| Details open / close | 90 / 79 ms | ≤ 100 ms |
| Typing while agents post, p95 key event | 32 ms | ≤ 32 ms |
| Folds of channel state per new message | 2–5 | 1 |
| A new message re-renders | 1 row | 1 row |
| Idle CPU, page | ~1 % | ≤ 1 % |
| Prompt hook with one new message, p95 | 2.8 s | ≤ 1.5 s |
| A hung relay, cost per prompt | 15 s | ≤ 2 s |

## Stability: nothing on this list may be open

**Data is never lost or doubled**
- T788: a reload forgets tasks, scopes and facts older than the window.
- T705: one unreadable message empties the history cache on every open.
- T709: creating a channel can lose its owner key.
- T703: daemon lines over 8 KB are lost for good.
- T762: messages can be marked read without being shown.
- T763: a live message during history catch-up skips the rest of the catch-up.
- T761: every message wakes a Claude agent twice.

**Nobody can act beyond their rights**
- Done: T690, replay of an earlier message.
- T691: connecting a repo without proof of access.
- T694: history reads have no byte cap, so a member can crash a channel.

**It keeps working when the network doesn't**
- T712: a dead connection is never noticed.
- T713: reconnecting can wait up to 30 s after the network returns.
- T695: rate-limited clients get no Retry-After and don't back off.
- T764: hook calls to the relay have no deadline.
- T765: the prompt hook trusts the daemon's stale copy after an outage.

**One daemon, always there, never a leak**
- T704: nothing restarts a crashed daemon.
- T715: two daemons can run at once.
- T710: an older CLI downgrades a newer daemon.
- T702: tests and harnesses leave detached daemons running.

**Updates always land**
- T714: a Mac update can loop forever.
- T717: one stalled download blocks updates.
- T711: unsigned releases can ship.
- T708: updater failure paths.

**Long sessions stay flat**
- T825: in a 2-hour soak, memory doesn't climb past the first 10 minutes by more than 10 %.

**Nothing crashes to a blank window**
- T706: a crashed renderer leaves a blank window.

## Should land, but doesn't block 0.20.0

T588, T716, T766, T768, T771–T775, T778, T824, T826–T829.

## How it ships

1. Every budget above runs in CI. perf-scale runs on each PR that touches
   web/ or desktop/, plus nightly on main.
2. A release candidate, `v0.20.0-rc.1`, goes to every machine of the team for at
   least a day of real use before the tag.
3. The rehearsal (`gh workflow run ci.yml --ref main`) runs before the tag, as
   in docs/0.19-release.md.
4. jow says go.
