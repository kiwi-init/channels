# GitHub

저장소를 연결하면 채널이 그 저장소의 풀 리퀘스트, 이슈, 체크, 푸시, 워크플로 실행을 실시간으로 봅니다. 릴레이는 채널을 읽거나 채널에서 서명할 수 없으므로 직접 게시하지 않습니다. 대신 간추린 쪽지를 대기열에 넣고, 다음에 앱이 열릴 때 앱이 서명하고 암호화해 게시합니다.

<!-- figure: github -->

## 설정

1. **계정을 연결하세요.** 앱의 설정 → **GitHub** → **GitHub 연결**을 누르면 코드가 표시되고 `github.com/login/device`가 열립니다. 그곳에 코드를 입력하고 승인하면 앱에 *@you(으)로 연결됨*이 표시됩니다. 토큰은 그 컴퓨터에 있는 앱의 암호화된 저장소에 남으며, 채널이나 에이전트에게 절대 가지 않습니다. **연결 해제**를 누르면 토큰을 삭제합니다.
2. **App을 설치하세요.** 저장소를 소유한 모든 계정이나 조직에서, 해당 저장소에 **Kiwi Channels**를 설치하세요.
3. 채널 설정의 **저장소**에서 **저장소를 연결하세요**. 연결된 계정으로 푸시할 수 있는 저장소만 연결할 수 있습니다.

저장소 목록이 바뀌면 앱은 그 요청 하나에 연결 토큰을 담아 릴레이에 보냅니다. 릴레이는 나로서 GitHub에 각 저장소에 푸시할 수 있는지 묻고, 하나라도 실패하면 목록 전체를 거부하며, 토큰은 전혀 보관하지 않습니다. 이 일을 맡길 만큼 신뢰하는 릴레이를 통해서만 저장소를 연결하세요. 요청 본문을 기록하는 릴레이라면 토큰을 보관할 수 있습니다.

## 릴레이가 보는 것

채널이 연결한 저장소, 그리고 앱이 가져가기 전까지의 각 이벤트입니다. 저장소, PR 번호와 제목, 브랜치, 커밋, 체크 이름과 결과, 그리고 누가 했는지입니다. 본문이나 diff는 절대 보지 않습니다. 모두 GitHub가 이미 가지고 있는 정보입니다. 대기열의 쪽지는 앱이 가져가면 삭제되고, 그렇지 않더라도 7일이 지나거나 500개가 쌓이면 삭제됩니다.

## 채널이 이미 가진 것

GitHub는 저장소가 연결된 뒤에 일어난 일만 보냅니다. 그래서 소유자의 앱은 앱이 열릴 때, 저장소가 연결될 때, 그리고 6시간마다 저장소의 열린 풀 리퀘스트와 그 체크, 열린 이슈, 지난 30일 동안 닫힌 것을 가져와 채널이 아직 모르는 것만 게시합니다.

GitHub 화면이 비어 있으면 그 이유를 알려 줍니다. 각 저장소에 App이 설치되었는지(설치되지 않았으면 설치 링크와 함께), 어떤 이벤트를 받는지, 마지막 웹훅이 언제 왔는지입니다. 조직으로 옮긴 저장소는 그 조직에도 App을 설치해야 합니다.

## 리뷰와 병합

Kiwi는 GitHub에서 병합을 막지 않습니다. 리뷰 판정은 작업의 라운드와 스레드에 남고, 리뷰어가 PR에 옮겨 적지 않습니다. 병합 전에 무엇을 필수로 할지는 저장소 자체의 규칙과 CI가 정합니다.

작업의 `merge` 단계는 소유자의 앱이 PR이 병합된 것을 보면 스스로 끝납니다. PR이 작업 승인보다 먼저 병합되었다면 단계의 메모에 그렇게 적힙니다.

구성원은 연결된 저장소에 한해, 릴레이를 통해 기본 브랜치 대비 커밋의 diff를 읽을 수 있습니다.

### 규칙이 아직 `kiwi/review`를 필수로 하는 경우

예전의 Kiwi는 채널마다 `kiwi/review/<채널 ID>` 체크를 게시했고, 브랜치 규칙에서 이를 필수로 지정할 수 있었습니다. 이 체크는 폐지되었습니다. 연결된 저장소의 규칙이 아직 이를 필수로 하는 동안에는 소유자의 앱이 그 저장소의 열린 PR마다 초록색 체크 "Retired: Kiwi no longer gates merges"로 응답하므로, 아무것도 이 체크를 기다리지 않습니다. 규칙에서 필수 지정을 지울 때까지 `kiwi status`와 작업 화면에 그 저장소 이름이 표시됩니다. Kiwi는 규칙을 읽어 필수 지정이 사라진 것을 확인하면 응답을 멈추며, 그 전에 날짜로 끝나지는 않습니다.

## 이슈가 작업으로

`kiwi task add --issue 12`는 채널 저장소의 이슈로 작업을 등록하며, 제목은 이슈를 따릅니다. 이슈가 닫히면 작업도 닫힙니다. 작업이 닫혀 이슈가 닫히는 것은 소유자가 *GitHub에 쓰기*를 켜 둔 동안뿐입니다.

## 직접 운영하는 릴레이에서

직접 운영하는 릴레이에는 별도의 GitHub App이 필요합니다. 단계는 [셀프 호스팅](self-hosting.md#github)에 있습니다.
