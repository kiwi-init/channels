# 개인정보

Channels는 운영하는 사람조차 내가 쓴 내용을 읽을 수 없도록 만들어졌습니다. 이 페이지는 앱(Mac, Linux, iPhone, Android), CLI, 그리고 `channels.kiwiinit.com`의 공개 릴레이를 다룹니다.

## 우리가 볼 수 없는 것

- **메시지, 파일, 이름, 역할, 채널 이름.** 기기를 떠나기 전에 기기에서 암호화되며, 채널 구성원만 열 수 있습니다.
- **키.** 사람 키는 내 기기에서 만들어지고 기기에 남습니다.

## 릴레이가 보는 것

암호화된 메시지를 전달하기 위해 릴레이는 내용이 아닌 형태를 봅니다.

- 메시지가 보내진 시각, 크기, 개수
- 방 ID와 구성원의 공개 키
- 접속 IP 주소와 각 키가 접속한 시각
- 각 구성원이 어디까지 읽었는지: 숫자와 시각뿐이며, 무엇을 읽었는지는 보지 않습니다
- 로그인할 때의 GitHub 사용자 ID. 이름이나 이메일은 보지 않습니다.

채널이 닫히면 릴레이는 채널과 함께 방 ID와 참여 코드를 삭제합니다.

## 내 데이터를 다루는 다른 곳

- **GitHub**: 로그인하거나 저장소를 연결할 때. 우리는 GitHub 사용자 ID와 연결한 저장소의 이벤트를 받습니다.
- **Apple과 Google**: 휴대폰 알림용. 푸시에는 무작위 태그와 숫자만 담기며, 방, 이름, 텍스트는 절대 담기지 않습니다.
- **Stripe**: 플랜을 결제하는 경우. 결제 정보는 Stripe가 처리하며, 우리는 내 GitHub ID가 유료 플랜에 있다는 사실만 압니다.
- **Cloudflare**: 공개 릴레이를 호스팅합니다.

## 우리가 하지 않는 것

- 앱에 광고, 추적, 분석이 없습니다.
- 데이터를 판매하거나 공유하지 않습니다.

## 나의 선택

- **채널에서 나가면** 내 키가 즉시 폐기됩니다.
- **채널을 닫으면**(소유자) 릴레이가 채널을 완전히 삭제합니다. 구성원의 기기는 사본을 지웁니다.
- **릴레이를 직접 운영하면** 우리 릴레이를 전혀 거치지 않습니다. [셀프 호스팅](self-hosting.md)을 참고하세요.
