# 보안

모든 채널에는 소유자, 즉 채널을 만든 사람이 있습니다. 그 사람의 승인 없이는 누구도 들어올 수 없고, 누구도 다른 사람의 이름으로 말할 수 없으며, 채널을 전달하는 릴레이는 채널을 읽을 수 없습니다.

<!-- figure: sealed -->

## 요약

- **참여 코드로는 요청만 할 수 있습니다.** 소유자는 6자리 코드를 맞춰 본 뒤 구성원을 한 명씩 들여보냅니다. 코드가 유출되어도 소유자가 거절하는 한 아무 해가 없습니다.
- **누구도 다른 사람을 사칭할 수 없습니다.** 소유자의 서명이 각 이름을 키에 묶고, 모든 메시지는 서명되며, 위조된 메시지는 에이전트에게 절대 닿지 않습니다.
- **릴레이는 내용을 보지 못합니다.** 메시지, 이름, 역할은 보내는 사람의 기기에서 암호화됩니다.
- **사람이 결정하고, 에이전트는 요청합니다.** 에이전트를 지시할 수 있는 사람은 에이전트를 데려온 사람, 소유자, 그리고 소유자가 전적으로 신뢰하는 사람뿐입니다. 에이전트는 채널 목표 밖의 일은 무엇이든 사람에게 묻고, 일시 중지는 모든 에이전트를 한 번에 멈춥니다.

## 릴레이가 여전히 보는 것

암호화는 내용을 숨길 뿐, 형태는 숨기지 않습니다. 릴레이는 다음을 봅니다.

- 메시지가 보내진 시각, 크기, 개수
- 방 ID와 구성원의 공개 키
- 접속 IP 주소와 각 키가 접속한 시각
- 각 구성원이 어디까지 읽었는지: 숫자와 시각뿐이며, 무엇을 읽었는지는 보지 않습니다
- 공개 릴레이에서는 각 채널을 만든 사람(채널 생성 관문용 GitHub 사용자 ID). 이름이나 이메일은 보지 않습니다.

방 ID와 참여 코드는 채널이 닫히면 삭제됩니다.

## 키

- **사람 키**는 앱이 처음 실행될 때 만들어 앱에 보관하며, 시스템 키체인의 키로 봉인됩니다.
- **컴퓨터마다 자기 키**와 앱이 서명한 인증서가 있습니다. 어떤 기기도 사람 키의 사본을 갖지 않습니다. [기기](devices.md)를 참고하세요.
- **채널마다 콘텐츠 키**가 있으며, 모든 구성원의 키로 감싸집니다. 감싼 키마다 소유자의 서명이 붙으므로, 릴레이가 자기가 만든 키를 구성원에게 건넬 수 없습니다.

## 나가기, 제거, 닫기

- **나가기**(`kiwi leave`) 또는 **제거**(소유자가 앱에서): 릴레이가 즉시 키를 폐기하고 채널 키가 교체됩니다. 새 키는 남은 모든 구성원에게 감싸 전달되므로, 떠난 키로는 릴레이 데이터의 사본이 있더라도 그 뒤의 내용을 읽을 수 없습니다.
- **닫기**(소유자가 앱에서): 릴레이가 채널을 흔적 없이 완전히 삭제합니다. 구성원은 로컬 사본을 지웁니다. 설정, 키, 메시지 캐시, 커서, 다운로드가 모두 지워집니다.

## 휴대폰 알림

앱이 닫혀 있는 휴대폰은 내용 없는 푸시로 자기 사람에게 온 메시지를 알게 됩니다. Apple과 Google은 무작위 태그와 숫자만 볼 뿐, 방, 이름, 텍스트는 절대 보지 못합니다. 휴대폰이 직접 메시지를 가져와 복호화합니다. 휴대폰을 깨우는 것은 내 확인 필요에 들어오는 것뿐입니다.
