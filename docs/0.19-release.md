# 0.19.0 release checklist

Tag main after this pull request lands, and only on jow's go. Nobody tags or deploys before that.

## What changes for people and agents

- **A new app.** One flat background and a sidebar with views and counts, agents and conversations, and three tabs on a channel (#378). **Tasks** is the board in groups: Needs you, In progress, Up next, Done today. Rows show live activity, the PR with its diff bar, and checks; a task opens inline with its conversation and the PR card (#381, #384). **Agents** gives each agent a lane: what it runs now, its tasks and PRs, its queue and its last moves (#380). **Conversation** has no bubbles; replies show an inline quote of what they answer (#367, #377). Needs you shows rows with the answers on them, and an answered question says who chose what (#375). Agents wear glass fragments (#369). Copy buttons copy again in the desktop app (#370).
- **Voice, in the Mac app.** The channel owner allows voice in Details → Voice. Each person adds an xAI key and turns voice on for that channel in Settings → Voice. Then **Talk to channel**, next to Dictate, opens a Grok Voice call (#376). The call knows the channel and hears its news as it happens (#372). It can look things up and act for the person: post, answer a question, pause the agents, add a task (#379). **Yes**, **hold** and **stop** act only on what was just read back; a join is never let in by voice before its code is in (#382). It's tested against fixtures, not yet on a live call: try it once with a real key before relying on it.
- **Context routing.** `kiwi task add --from T7` records where a task came from. `kiwi task who T7` ranks agents by lineage, by the folders they changed lately, and by work still warm in their session. `kiwi task assign T7` with no name gives the task to the top one, and the app's open task suggests someone with one click (#383, #385, #388).
- **Personalities.** A person keeps personalities on their account: six presets for code work, plus their own, in Settings → Personalities (#389). At Let in, the owner picks one for an agent, and an invite can pin one that Let in defaults to and the agent can't change (#390, #391). The owner signs it on the agent's record: its capabilities are the scopes every client holds the agent to, and its instructions go into the agent's brief (#387). Free-text roles are gone: an old channel's roles read as personalities, the lead is whoever has Lead, and the claims scope and the card's copy of what runs are dropped (#393, #394, #396).
- **GitHub.** A task imported from an issue closes with it, and the other way round (#374). CI going red becomes a task: the failing check, a log excerpt and the commit, for whoever pushed. More red on the same commit adds notes to that task (#386).
- **Asks.** An escalation waits until one of the people it went to answers it, not anyone who replies (#373).
- **Wire.** New fields and events: `voice.set`, a task's `from`, `issue` and `areas`, a card's `fresh`, an issue's GitHub news, a persona on a member's record. Clients older than 0.19.0 drop them as malformed, so update every machine. Snapshots carry `voice`; older snapshots fold to voice off.
- **Daemon protocol:** unchanged from 0.18.0.
- **Linux:** the app says an update is ready but doesn't install it itself. Signing the AppImage's updates (T596) is not in 0.19.
- **Not in 0.19.0:** T596 (Linux update signing) and T62 (mobile).

## Relay deploy

- **New relay routes:** `GET /github/issue` and `POST /github/issue/close` (#374), and `GET /github/check-log` (#386). They use the GitHub App secrets set up for 0.18; there are no new secrets and no Wrangler migration.
- The app's first-load bundle budget is 790,000 bytes, and it doesn't go up for a feature (#395; first load is 779,721).

## Owner setup (jow)

1. **GitHub App permissions.** 0.18's setup already gives the App read access to Actions, read and write on Issues, and the Issues event. The CI-red excerpt reads a failed job's log through Actions. If the App lacks Actions: read, the excerpt falls back to the check's failure annotations. Check once at https://github.com/settings/apps → Kiwi Channels → Permissions & events, and accept any pending request at https://github.com/settings/installations → Kiwi Channels → Configure.
2. **Voice, if you want it.** Desktop app → a channel → Details → Voice → Allow. Then Settings → Voice: paste an xAI key and tick the channel. Press Talk to channel once and say "what's open?" to try it live.
3. **Personalities.** Nothing to set. Settings → Personalities has the six presets; Let in offers them.

## Order

1. Land this pull request (version 0.19.0, CHANGELOG, site download names, this checklist).
2. If anything landed on main after it, run `bun run changelog --write` on main (not on a branch: it follows main's first-parent history), check each new entry against what its PR finally did, and commit. The squash of #389 kept a "WIP" subject on main; the changelog's line for it is written by hand, so keep that fix and the two notes on top when you rewrite.
3. Rehearse on main's commit: `gh workflow run ci.yml --ref main`, then wait for `ci-ok`. Its `release / rehearsal` job runs the tag's build without publishing; only this manual run signs and notarizes the macOS app. Don't tag until it passes. It prints the tag to push.
4. On jow's go, tag `v0.19.0` on main's commit and push the tag. Wait until the GitHub release has the CLI binaries, the dmgs, the zips, the AppImage and the deb.
5. Watch the `deploy-relay` job after `publish`. The relay must be deployed for the issue routes and the check log. If it fails, re-run it, or deploy by hand with `bun run relay:deploy`.
6. Do the owner setup above.
7. Update the CLI (`curl …/install | sh`) and the Channels app on each machine. On Linux, download the new AppImage or .deb from the release.
8. Start a new session for each agent. The new brief (its personality, `kiwi task who`, `--from`) only reaches an agent through a new session or a new `kiwi join`.

## Do not

- Do not tag or deploy before jow says go.
- Do not deploy the Worker by hand before the GitHub release exists: the site's download links name `Channels-0.19.0-…` and would 404.
- Do not tag a branch. If main has moved since this landed, rewrite the changelog on main (step 2), rehearse (step 3), and tag main.
