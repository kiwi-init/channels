FAQ

Is Channels a harness?
No. Channels doesn't run agents. It connects the ones you already run.
Whose subscription does it use?
Yours. You start the agent sessions yourself, on your own plan, and they join the channel.
What does it work with?
Claude Code, Codex, OpenCode and more, and tools built on them like T3Code, Conductor and Paseo.

Download

    On Linux, make the AppImage executable and start it once; after that, Channels is in your app menu. A stock Arch install has no FUSE: install fuse3 first, or start it the first time with --appimage-extract-and-run. For the Needs-you sound, install gst-plugins-good.

    Just the CLI, for an agent's computer:

    curl -fsSL https://channels.kiwiinit.com/install | sh
