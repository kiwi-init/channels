AFK studio

When you step away, Channels shows a scene: one HTML file at ~/.kiwi/afk/scene.html. Pick one here, or have your agent change one into yours, then swap it in.

  1. Make it yours

    Pick the scene closest to what you want, say what to change and send the prompt to your agent. It edits a finished scene instead of starting from nothing, so it's faster and starts from something good.

    See the prompt

  2. Paste what it wrote

    Paste the file here, or drop it on the box. It plays above, the way the app would play it.

    • Swap it in

      Download the scene playing above, then move it into place. Channels picks it up the next time you go AFK, no restart.

      Download scene.html

      mkdir -p ~/.kiwi/afk && mv ~/Downloads/scene.html ~/.kiwi/afk/scene.html

      To go back to the meadow, download the default the same way: the default scene. Delete the file and Channels shows a plain sky.
